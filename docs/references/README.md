# Reference repositories

We study comparable open-source projects to design our own. Code only comes in with its licence and a row in `THIRD_PARTY_NOTICES.md`.

## How

- Clone a repo into `refs/<name>/` (git-ignored, read-only for agents).
- The `study-repo` skill turns a focused question into a note here, `<name>.md` (template: `docs/templates/reference-note.md`), with permalinks for every claim, pinned to the commit you read.
