# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the repository's issues, pull requests and discussions, and wherever someone represents the project.

## Reporting

To report a problem in private, open a [private security advisory](https://github.com/PedramRZM/truing/security/advisories/new) and say it concerns conduct, not a vulnerability. If it doesn't need to be private, you can [open an issue](https://github.com/PedramRZM/truing/issues/new/choose).

Reports are reviewed promptly and kept confidential as far as the matter allows. The maintainers follow the enforcement guidelines in the Contributor Covenant.
