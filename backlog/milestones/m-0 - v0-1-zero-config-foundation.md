## Description

Run `truing` in any folder and get to your real app in Truing's window with no config file. Claude Code is checked for real, Claude reads the project into a profile and asks when it can't tell, and a person confirms the start command before anything runs. Hardening of Claude in Truing comes before anyone else uses it.
